# CV / resume material (Orbital Explorer)

## One-line bullet

**Orbital Explorer:** open-source 3D visualiser for atomic and molecular orbitals (hydrogenic AOs, Huckel pi MOs, diatomic MO diagrams). Python (Dash/Streamlit), pytest suite for the physics, Docker and GitHub Pages demo. MIT, v0.1.0.

## Longer (projects section)

Built **Orbital Explorer** as a free revision aid for undergrad MO theory: exact hydrogenic s/p/d/f orbitals in 3D, Huckel pi systems with an LCAO "orbital sharing" view and HOMO/LUMO diagrams, and diatomic ladders that match standard textbook results (including O2 paramagnetism). Packaged under MIT with tests, CI, and a public demo.
