Run the full app

git clone https://github.com/nikshaybisht/orbital-explorer.git
cd orbital-explorer
pip install -e ".[all]"
python run_app.py
# or: streamlit run streamlit_app.py

Dash on port 8050 · Streamlit for free cloud hosts · Docker · Render

What this is

Teaching tool: exact hydrogenic wavefunctions, qualitative Huckel and diatomic MO diagrams. Not Gaussian / ORCA. Honest scope, 39 chemistry unit tests, CI on Ubuntu and Windows.
